# テスト仕様書

要件([ルートの CLAUDE.md](../CLAUDE.md))、ゲームのルール([src/lib/CLAUDE.md](../src/lib/CLAUDE.md))、画面([src/components/CLAUDE.md](../src/components/CLAUDE.md))を確かめるテストの一覧。テストのファイルは、書く前の予定。

- 単体・コンポーネントは Vitest + React Testing Library、E2E は Playwright Test。
- API と DB は無いので、それらのテストは無い。
- 乱数は引数で渡し(G-02)、本番のコードにテスト用の分岐を入れない。
